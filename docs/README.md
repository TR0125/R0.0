# `raybot_chassis_ws` 文档导航

## 1. 使用入口（先看这里）

如果你只想“快速上手”，按这个顺序阅读：

1. `对外接口文档.md`（协议与接口定义）
2. `部署与启动.md`（可执行步骤，含新开终端操作）
3. `联调与验收.md`（联调动作与通过标准）
4. `故障排查.md`（问题定位）
5. `架构与设计.md`（理解代码结构与职责）

---

## 2. 按角色选文档

- 总控/调度对接：`对外接口文档.md` + `联调与验收.md`
- 现场实施/运维：`部署与启动.md` + `故障排查.md`
- 开发维护：`架构与设计.md` + `文档维护SOP.md`

- 一文一责：同一主题只保留一个主入口

- 历史专题优先标记 `archive`，避免入口分散
