## 1. 实现范围

当前工作区实现的是“调度协议任务控制 + 回调接收 + 总控单 topic 桥接”这一条路线。

当前现场默认参数：

- 机器人控制地址：`http://192.168.1.55:8283`
- 香橙派回调地址：`http://192.168.1.25:8283`
- `robot_id`：`ubot-001`

## 4. 当前总控命令模型

总控推荐通过 `/chassis/command` 下发命令。

兼容期保留 `/chassis/command_legacy`。

当前支持的 `command_type`：

- `SET_MODE`
- `STOP`
- `MOVE`
- `ROTATE`
- `GOTO_POSE`
- `GOTO_GOAL`
- `GO_HOME`
- `CHARGE`
- `PATROL_GOALS`
- `REQUEST_STATUS`
- `CANCEL_MISSION`

mission 型命令会自动补齐默认任务标识：

- `mission_name`：语义化名称，例如 `GotoGoalA`
- `mission_id`：递增实例号，例如 `goto-a-001`、`goto-a-002`

如果总控显式传入 `mission_name` 或 `mission_id`，桥接节点优先使用总控给定值。

## 5. 当前边界

当前没有提供以下能力：

- 实时连续 `vx / vy / vt` 速度流控制
- 标准 ROS `cmd_vel` 控制接口
- 任务暂停与恢复

补充说明：

- `PATROL_GOALS` 对应单条 mission：到目标点 -> 等待 -> 返回起点
- `patrol-goals` 当前执行流程是“到目标点 -> 等待 -> 返回起点”
- 横移不是协议原生动作，而是基于当前位置构造 `goto pose`
