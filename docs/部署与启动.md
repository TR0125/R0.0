# 部署与启动（含新开终端步骤）

状态：`active`

## 1. 目标

本文用于把系统稳定拉起，确保以下链路可用：

- HTTP 回调网关：机器人 -> 香橙派
- 命令桥接：总控 Topic -> 机器人 HTTP
- 位姿桥接：`/protocol/robot_status` -> `/raybot/base_pose`

---

## 2. 前置检查

- 代码目录：`/home/raybot/raybot_chassis_ws`
- ROS：Humble
- 默认地址：
  - 机器人：`http://192.168.1.55:8283`
  - 香橙派：`http://192.168.1.25:8283`
- 网络互通（双向）：
  - 香橙派能访问机器人 `8283`
  - 机器人能回调香橙派 `8283`

---

## 3. 终端约定（非常重要）

每个“新开终端”都必须执行以下两条命令：

```bash
source /opt/ros/humble/setup.bash
source /home/raybot/raybot_chassis_ws/install/setup.bash
```

如果你忘了执行，典型现象是：

- `ros2 launch` 找不到包
- 话题/节点显示异常

---

## 4. 首次或代码更新后编译

在任意一个终端执行：

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select raybot_chassis_msgs raybot_chassis_master chassis_move
source install/setup.bash
```

---

## 5. 标准启动步骤（按终端分配）

### 终端 1：启动协议回调网关

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch chassis_move protocol_bringup.launch.py
```

### 终端 2：启动统一命令桥接

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch chassis_move protocol_command_bridge.launch.py
```

### 终端 3：启动 base_pose 位姿桥接

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch chassis_move robot_status_pose_bridge.launch.py
```

### 终端 4：观察窗口（建议）

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /chassis/command_result --full-length
```

再新开一个终端 5 观察状态：

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /protocol/robot_status --full-length
```

再新开一个终端 6 观察位姿：

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /raybot/base_pose --full-length
```

---

## 6. 启动成功判据

- `protocol_bringup` 无端口占用错误
- `protocol_command_bridge` 持续运行，无参数异常
- `robot_status_pose_bridge` 有启动日志，且 `base_pose_topic=/raybot/base_pose`
- 机器人回调来数据时，`/protocol/robot_status` 有输出
- `/raybot/base_pose` 持续更新（单位米）
