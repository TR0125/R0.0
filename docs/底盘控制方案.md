> 
> 主入口请优先使用：`架构与设计.md` 与 `对外接口文档.md`。

## 1. 控制思路

当前底盘控制采用厂商调度协议，不走实时 `cmd_vel`。

控制链路分成两部分：

- 控制命令：发给机器人本体 `http://192.168.1.55:8283`
- 状态回调：由香橙派 `http://192.168.1.25:8283` 接收

因此当前实现属于“任务型控制”，不是“高频速度流控制”。

## 2. 协议能力边界

协议当前可直接承载的动作：

- `move`
- `head`
- `goto`
- `charge`
- `stop`

对应控制语义：

- 前进/后退：`move`
- 原地旋转：`head`
- 到目标点或位姿：`goto`
- 停止：`stop`
- 充电：`charge`

当前不提供：

- 连续 `vx / vy / vt` 下发
- 标准 `/cmd_vel`
- 低延迟实时手操速度闭环

## 4. 总控推荐接入方式

总控侧建议只保留一个入口 topic：

- `/chassis/command`

兼容期 legacy 入口：

- `/chassis/command_legacy`

当前支持的命令类型：

- `SET_MODE`
- `STOP`
- `MOVE`
- `ROTATE`
- `GOTO_POSE`
- `GOTO_GOAL`
- `GO_HOME`
- `CHARGE`
- `PATROL_GOALS`
- `REQUEST_STATUS`
- `CANCEL_MISSION`

当前推荐消息体使用 `raybot_chassis_msgs/msg/ChassisCommand`。

兼容说明：

- `/chassis/command`：`raybot_chassis_msgs/msg/ChassisCommand`
- `/chassis/command_legacy`：`std_msgs/String`，其中 `data` 为 JSON 字符串

推荐通过本地总控包发命令：

```bash
ros2 run raybot_chassis_master chassis_master_cli -- goto-goal --goal A
```

示例：

```bash
ros2 topic pub --once /chassis/command raybot_chassis_msgs/msg/ChassisCommand \
  "{command_type: GOTO_GOAL, goal: A}"
```

AB 点往返示例：

```bash
ros2 run raybot_chassis_master chassis_master_cli -- \
  patrol-goals --from-goal B --to-goal A --wait-at-goal-sec 10
```

legacy 示例：

```bash
ros2 topic pub --once /chassis/command_legacy std_msgs/msg/String \
  "{data: '{\"command_type\":\"PATROL_GOALS\",\"from_goal\":\"B\",\"to_goal\":\"A\",\"wait_at_goal_sec\":10}'}"
```

## 5. mission 命名规则

桥接节点对 mission 型命令默认采用：

- `mission_name`：语义化任务名
- `mission_id`：同类任务递增编号

示例：

- 第一次去 `A`：`mission_name=GotoGoalA`，`mission_id=goto-a-001`
- 第二次去 `A`：`mission_name=GotoGoalA`，`mission_id=goto-a-002`

说明：

- 同一条任务的 `STARTING`、`RUNNING`、`SUCCEED` 会共用同一个 `mission_id`
- 同一种任务再次下发时，会生成新的 `mission_id`
- 这套命名规则只适用于 `/chassis/command` 桥接节点
- `protocol_cli` 直接下发任务时，默认 `mission_name` 仍是 `ManualMove`、`ManualHead`、`ManualGotoGoal`
- `PATROL_GOALS` 默认会生成类似 `PatrolBToA` / `patrol-b-to-a-001` 的任务标识

## 6. 当前适用场景

适合：

- 总控下发离散动作
- 到点导航
- 回家
- 充电

不适合：

- 高速实时遥控
- 轨迹跟踪型速度控制
- 需要连续速度闭环的上层算法
