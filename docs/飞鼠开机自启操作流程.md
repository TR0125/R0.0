# 飞鼠控制与开机自启操作流程

> 状态：`archive`
> 
> 主入口请优先使用：`部署与启动.md`。

本文目标：实现“香橙派与底盘上电后，飞鼠可直接控制底盘”，无需手动 SSH 启动控制节点。

## 1. 前置条件

- 香橙派、底盘、路由器已接入同一局域网并互通
- 飞鼠接收器已插入香橙派 USB
- 代码目录为 `/home/raybot/raybot_chassis_ws`
- ROS 版本为 Humble（按现场环境）

说明：

- 飞鼠本身不依赖路由器；
- 但当前控制链路是香橙派通过 HTTP 控制底盘，因此香橙派与底盘之间必须有可用网络。

## 2. 确认飞鼠输入设备路径

建议使用稳定路径 `/dev/input/by-id/...`，不要直接写 `/dev/input/eventX`（重启后可能变化）。

```bash
ls -l /dev/input/by-id
```

记录飞鼠对应路径（示例）：

- `/dev/input/by-id/usb-XXXX-event-kbd`
- `/dev/input/by-id/usb-XXXX-event-mouse`

下文用 `<AIR_MOUSE_EVENT_PATH>` 代表该路径。

## 3. 编译并加载工作区

```bash
cd /home/raybot/raybot_chassis_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select chassis_move
source install/setup.bash
```

## 4. 手动启动验证（先确认可控）

```bash
ros2 launch chassis_move protocol_airmouse_bringup.launch.py \
  robot_base_url:=http://192.168.1.55:8283 \
  robot_id:=ubot-001 \
  input_event_path:=<AIR_MOUSE_EVENT_PATH>
```

验证动作是否生效：

- 前进 / 后退
- 左右转
- 停止

若验证通过，`Ctrl+C` 退出，继续配置开机自启。

## 5. 配置 systemd 开机自启

创建服务文件：

```bash
sudo tee /etc/systemd/system/raybot-airmouse.service >/dev/null <<'EOF'
[Unit]
Description=Raybot protocol airmouse bringup
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=raybot
WorkingDirectory=/home/raybot/raybot_chassis_ws
Environment=PYTHONUNBUFFERED=1
ExecStart=/bin/bash -lc 'source /opt/ros/humble/setup.bash && source /home/raybot/raybot_chassis_ws/install/setup.bash && ros2 launch chassis_move protocol_airmouse_bringup.launch.py robot_base_url:=http://192.168.1.55:8283 robot_id:=ubot-001 input_event_path:=<AIR_MOUSE_EVENT_PATH>'
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
EOF
```

启用并立即启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now raybot-airmouse.service
```

## 6. 查看运行状态与日志

```bash
systemctl status raybot-airmouse.service
```

```bash
journalctl -u raybot-airmouse.service -f
```

## 7. 常见问题处理

### 7.1 提示无权限读取 `/dev/input/...`

日志类似：

- `No permission to read input device ...`

处理：

```bash
sudo usermod -aG input raybot
```

执行后重启香橙派（或重新登录）使组权限生效。

### 7.2 找不到输入设备

先复查路径：

```bash
ls -l /dev/input/by-id
```

更新 service 中的 `input_event_path` 后重载并重启服务：

```bash
sudo systemctl daemon-reload
sudo systemctl restart raybot-airmouse.service
```

### 7.3 底盘无响应

按顺序排查：

- 底盘与香橙派网络是否互通
- `robot_base_url` 是否正确（应为底盘控制地址）
- 服务日志中是否有 HTTP 请求错误
- 机器人当前是否在可执行任务模式（如 `AUTOMATIC`）

## 8. 开机即控验收清单

1. 路由器上电  
2. 底盘上电  
3. 香橙派上电  
4. 等待系统与服务启动（约 20~40 秒）  
5. 操作飞鼠，底盘可直接响应（无需手动 SSH 启动节点）

验收命令：

```bash
systemctl is-enabled raybot-airmouse.service
```

```bash
systemctl is-active raybot-airmouse.service
```

期望结果分别为：

- `enabled`
- `active`
